> **국립부경대학교 공식 영자신문사 'The PKNU Herald'의 기사를 언제 어디서나 쾌적하게 열람할 수 있도록 설계된 모바일 최적화 웹 애플리케이션**  
> 글로벌 학내 구성원과 외국인 유학생을 위해 직관적인 기사 큐레이션, 카테고리 필터링, 그리고 모바일 반응형 뷰어를 제공합니다.

---

## 📌 Key Highlights

- **모바일 퍼스트 UX/UI**: 지면 신문의 긴 영어 기사를 스마트폰에서도 편안하게 읽을 수 있는 타이포그래피 및 가독성 최적화.
- **카테고리별 아티클 큐레이션**: Campus, Society, Culture, Editorial 등 섹션별 필터링 및 최신 기사 피드 제공.
- **Next.js 기반 고성능 렌더링**: SSR/SSG를 통한 빠른 초기 로딩 속도 및 SEO 최적화.
- **반응형 디자인 시스템**: Tailwind CSS 기반의 클린하고 모던한 신문사 브랜딩 UI 구축.

## 🚀 Getting Started

### 1. Repository Clone
```bash
git clone https://github.com/yj2da/pknu_herald-app.git
cd pknu_herald-app
```

### 2. 의존성 설치 및 실행
```bash
npm install
npm run dev
# 브라우저에서 http://localhost:3000 접속
```
